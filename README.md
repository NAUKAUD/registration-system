
# Registration System

## Project Description
A registration application developed using React.

## Technologies Used
- React.js
- JavaScript
- CSS
- Docker
- GitHub
- Docker Hub

## How to Run Locally

1. Clone the repository.
2. Run npm install.
3. Run npm run dev.

## Docker Instructions

Build the image:

docker build -t registration-system .

Run the application:

docker run -d -p 8080:80 registration-system
